# Shravanth M — AI & ML Engineer Portfolio

A modern, responsive, glassmorphic portfolio showcasing engineering projects, machine learning models, predictive pipelines, data analytics dashboards, and academic credentials.

## 🚀 Live Demo
- **Hosted on Vercel**: Accessible publicly worldwide
- **Domain**: [https://portfolio-shravanth.vercel.app](https://github.com/shravanthm/portfolio)

## 🛠️ Tech Stack & Features
- **Frontend**: Vanilla HTML5, CSS3 (Modern Glassmorphism & Micro-animations), JavaScript (ES6+)
- **Theme**: Dark Mode (Default) & Clean Light Mode toggle
- **SEO & Performance**: Fully optimized semantic markup, meta tags, OpenGraph, `robots.txt`, and `sitemap.xml`
- **Interactive Capabilities**:
  - Dynamic typewriter hero animation
  - Filterable Technical Skills matrix
  - Project Architecture & Workflow modals
  - One-click copy for contact details with visual toast feedback
  - Direct PDF Resume download link

## 📂 Project Structure
```
portfolio/
├── index.html        # Main landing page & semantic markup
├── style.css         # Custom design system, tokens, and animations
├── script.js         # Interactive features and event handlers
├── robots.txt        # Search engine indexing configuration
├── sitemap.xml       # SEO site indexing structure
├── assets/
│   ├── profile.jpg   # High-resolution profile portrait
│   └── resume.pdf    # Downloadable CV
└── README.md         # Project documentation
```
